Human Milk Microbiome Research: Dataset Feasibility Audit

Audit date: 7 November 2026
Stage: Phase 1 — source discovery and initial feasibility review

Important scope limitation: This is an initial source-level audit, not a completed data-quality audit. Original abundance files and full metadata exports have not yet been downloaded and programmatically inspected. No statistical tests, diversity estimates, model results, or biological conclusions have been generated.

1. PRIME database

PRIME's current download documentation reports 111 projects and 53,449 samples, with project/sample metadata exports and pre-built abundance tables at six taxonomic ranks (phylum through species). Both observed abundance and relative abundance are offered for SILVA 138.2 and Greengenes2 2024.09. The database documents an API and an R client. The 53,449 figure is the entire database, not the breast-milk subset.

2. MAMI database

The MAMI resource page explicitly lists mother_breastMilk_accession.txt and mother_breastMilk_abundance.csv. The accession resource is exposed as a 1,129-line text file: one header plus 1,128 data rows. Its columns include Run, Study, Category, Sample type, Sequencing strategy, Maternal age, Sampling days (since birth), Gestational status, Gestational age, perinatal_stage, Sex, Country, City, and Mode of delivery. Some visible rows contain blank or “unknown” values; field presence therefore must not be confused with complete metadata. A block of 159 India/Vellore records is visible in rows 965–1123, but full-country counts require parsing the complete downloaded file.

4. Acquisition and validation blockers

  • The web retrieval layer could read the MAMI accession text but rejected the abundance CSV as an unsupported text/csv response. Direct network retrieval from the execution environment also failed due DNS/network resolution. This is an access limitation in this run, not evidence that the source file is missing.
  • PRIME's web download page documents the required exports, but the exact breast-milk subset size has not yet been established from a full sample metadata export or API query.
  • Without the abundance matrices, we cannot report taxa counts, matrix dimensions, zero prevalence, sample overlap, diversity, or statistical results.
  • Participant-level identifiers and mother–infant matching must be verified before any paired analysis. Sample IDs and participant IDs are not interchangeable.

5. Recommended primary design, subject to the completed audit

Use MAMI's maternal breast-milk cohort as a focused candidate primary cohort because the resource explicitly separates breast-milk accessions and provides study and country fields. Use PRIME as an independent harmonized resource and potential replication/extension cohort only after confirming that its breast-milk body-site records and taxonomic tables overlap cleanly. Do not concatenate cohorts until taxonomy, feature definitions, sample identifiers, sequencing methods, and study effects have been assessed. For geographic analyses, country may be inseparable from study/batch; study-aware validation and confounder checks are essential.
